01Service

Claude Codeを、「知っている」から
「自分で動かせる」状態へ。

AIエージェント初期導入パック

ひとことで言うと 2回のハンズオンでClaude CodeをあなたのPCで動かせるようにして、御社の業務をひとつ、実際に自動化して納品するサービスです。

講義は最小限。経営者自身がキーボードに手を置いて、AIエージェントに最初の仕事を任せるところまで、隣で伴走します。 受けて終わりの研修ではなく、使える環境が手元に残る導入サービスです。

導入すると、こうなる
  • 請求書の仕分け・議事録の要約・問い合わせの分類など、定型業務をAIが毎日こなすようになる
  • あなた自身がClaude Codeに指示を出して、調査や資料の下書きを任せられるようになる
  • 御社所有のAIの作業場と手順書が残り、2件目以降の自動化を自分たちで増やせるようになる
対象 経営者おひとり、または経営者＋実務担当者（推奨1〜2名）
形式 90分×2回のハンズオン＋セッション間の環境構築（私たちが行います）
扱うもの Claude Code / Codex / GitHub — AIエージェントを業務で使うための基本セット
ゴール 請求書PDFの仕分け、議事録の要約、問い合わせの分類など、標準自動化パック6種から1つを御社の実務データで動かす
サポート 導入後14日間のチャットサポート。つまずきをその場で解消します
セキュリティ 作業環境は御社所有のPrivateリポジトリ。サポート期間終了後、私たちのアクセス権は標準で停止します

手元に残るもの

  • 御社所有のPrivateリポジトリ — AIが働く作業場そのもの
  • 操作マニュアル — 社内共有できる、御社の環境に沿った手順書
  • 御社専用プロンプト集 — 明日からそのまま使える指示文
  • 標準自動化パック1件 — 実装済み・動く状態で納品
  • 次の一手のご提案 — 御社の業務でAIに任せられる領域の見立て
料金について。 事例掲載にご協力いただける企業様には、特別条件でご提供しています。 詳細はお問い合わせの際にご案内します。

02Service

AI活用を、個人技から
会社の業務資産へ。

AI業務OS構築

ひとことで言うと どの業務をAIに任せられるかを診断し、会社ぐるみでAIが働く仕組みを設計して、実運用まで伴走するサービスです。

従業員10〜100名のB2B企業のための、業務再設計サービスです。 ツールの使い方ではなく、業務そのものをAI前提に設計し直すことに焦点を当てます。 四つの段階に分かれ、各段階の終わりに成果物が残ります。だから、段階ごとに「続けるか」を判断できます。

導入すると、こうなる
  • どの業務をAIに任せ、どこを人が判断するかが、経営判断として明確になる
  • 特定の人に頼っていた仕事の進め方が、会社の資産として蓄積され始める
  • AIの成果物が、決めた品質チェックを通ってから外に出るようになる
1. 診断
AUDIT / 2〜3営業日		 業務の流れ、情報の在り処、いまのAI活用状況を棚卸しします。
成果物：業務フローマップ / 情報ソース一覧 / リスクと機会のリスト
2. 設計
BLUEPRINT / 5〜7営業日		 AIと人の役割分担、品質チェックの関所、情報の置き場所を設計図に起こします。
成果物：役割カード一式 / 品質ゲート定義 / 情報の地図（どこに何を置くか）
3. 試運転
PILOT / 2〜4週間		 設計を実際の業務で回し、導入前後の変化を確かめます。
成果物：Before/After比較 / 実運用の課題ログ / 改善済みの運用手順
4. 伴走
RETAINER / 月次		 月次レビューで仕組みを育て、適用範囲を広げます。
成果物：月次レビュー記録 / 次に広げる業務の優先順位リスト
大手コンサルより軽く、顧問契約より深く。 月次の助言で終わる「顧問型」ではなく、設計図と運用の仕組みを納品する「設計型」です。 料金はお見積り制。まず診断（Audit）だけの実施もできます。

これから：支援の中で検証された業務パターンは、テンプレートとして磨き込み、将来はより多くの会社がそのまま使える形での提供を目指しています。
